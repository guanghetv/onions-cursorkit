# /qa-sync-xmind

test-spec.md 与 XMind 双向转换。`/qa-sync-xmind export` 生成 XMind 文件供飞书项目导入；`/qa-sync-xmind import` 将 XMind 中的调整同步回 test-spec.md。依赖 mcp-xmind MCP Server。

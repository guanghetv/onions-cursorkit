# /pm-proto

在需求目录中快速生成或更新原型资产。该命令只负责原型，不做 PRD 确认。

**门禁（不可跳过）**：须先 **Read 并遵循 `superpowers:brainstorming`**，与产品确认执行模式与本轮变更单后，才可写入 `prototypes/`。禁止「先出一版」代替澄清。

默认按“保留/新增/删除/调整”变更单做局部更新；首轮确认后锁定视觉与交互基线，改基线需显式确认。迭代结束输出「本轮已改/未改」摘要并通过快速验收门（主路径、锚点、视觉错位）。建议补充关键截图后执行 `/pm-spec`；无截图也可继续（不阻断）。

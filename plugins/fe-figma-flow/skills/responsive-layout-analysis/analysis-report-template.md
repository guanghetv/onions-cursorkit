> "—" 表示继承上一个断点的值，无变化。

**变化说明**：
- ≥640×640：仅放大尺寸（高度 32→40，字号 14→18，圆角 16→20）
- ≥1024：宽度从自适应改为固定 200px
- 横屏：收缩为图标模式，隐藏文字，宽度固定 32px

**实现方案**：
```scss
@mixin default {
  .search { flex-grow: 1; height: 32px; border-radius: 16px; }
}
@include default;

@media (max-width: 374px) {
  @design-width 375px;
  @design-unit vw;
  @include default;
}
@media (min-width: 640px) and (min-height: 640px) {
  .search { height: 40px; border-radius: 20px; }
}
@media (min-width: 1024px) {
  .search { flex-grow: unset; width: 200px; }
}
@media (max-height: 639px) and (orientation: landscape) {
  .search { flex-grow: 0; width: 32px; }
}
```

## 填写说明

### 属性对比表规则

- 所有尺寸值为 **1x**（设计稿值 ÷ 2）
- "—" 表示**继承**上一个生效断点的值，不需要在该断点额外写样式
- 使用 ✅/❌ 标记元素在该断点是否可见
- 宽度标注方式：`flex:1`（自适应）、`200px`（固定）、`100%`（占满）

### 实现方案规则

- 必须遵循 `responsive-layout` skill 中的 7 级断点顺序
- 使用 `@mixin default` + `@include default` 模式处理默认样式和小屏缩放
- 禁止媒体查询嵌套
- 优先使用弹性布局自适应，减少硬编码

### 变化说明规则

- 用简洁的文字描述变化的**原因**和**效果**，不是单纯复述数值
- 对于复杂变化，说明从哪个断点到哪个断点发生了什么
